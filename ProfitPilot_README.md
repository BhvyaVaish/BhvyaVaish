## 📌 Overview

ProfitPilot is an intelligent business assistant tailored specifically for Micro, Small, and Medium Enterprises (MSMEs). It combines essential business management tools with advanced AI capabilities to help small businesses make data-driven decisions, streamline operations, and maximize profitability.

## ✨ Key Features

- **📦 Inventory Management:** Track stock levels in real-time and get automated low-stock alerts.
- **🧾 Smart Billing:** Generate professional invoices quickly and easily.
- **📊 Sales Analytics:** Visualize sales trends and identify top-performing products/services.
- **🔮 Demand Prediction:** Leverage AI to forecast future product demand and optimize inventory ordering.
- **💡 Smart Insights:** Receive actionable, AI-generated insights based on your business data to identify growth opportunities.

## 🚀 Getting Started

Follow these steps to run ProfitPilot locally on your machine.

### Prerequisites

- Node.js (v18+)
- Python (3.9+)
- (Any other required software like Docker, PostgreSQL, etc.)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/BhvyaVaish/ProfitPilot.git
   cd ProfitPilot
   ```

2. **Set up environment variables:**
   Copy the example environment file and fill in your credentials.
   ```bash
   cp .env.example .env
   ```

3. **Install Dependencies (Backend):**
   ```bash
   # Navigate to backend folder if applicable
   cd backend
   pip install -r requirements.txt
   ```

4. **Install Dependencies (Frontend):**
   ```bash
   # Navigate to frontend folder if applicable
   cd ../frontend
   npm install
   ```

5. **Run the Application:**
   ```bash
   # Start backend
   python app.py

   # Start frontend
   npm run dev
   ```
